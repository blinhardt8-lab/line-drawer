# Line Drawer
2026 Java Project by Brett Linhardt  
A lightweight, pure-console line drawer, partially inspired by the Bresenham Line Function. Input two points, and the program calculates the line between them!

## Key Features
* **Text-Based Rendering**: Since this project prints directly to the console, there are no graphics. All "pixels" are a set of two monospace characters, only "turned on" if they are a special character (like the x or y axis) or are part of the line (denoted by "$$"). 
* **Floating-Point Rasterization**: Each "pixel" checks if its center is within 0.5 units vertically of the slope equation generated by the two points. If the "error" is less than or equal to 0.5, it is the closest approximation to the true slope on that specific x-coordinate.
* **Equation Generator**: Once the line is printed, the console also outputs the equation that can be used to create the same line on any other graphing calculator, with a slope and y-intercept. The console even returns bounds if the line does not touch both ends of the x-axis.
